# 2026 Senate and Governor headshot audit

Audit date: November 3, 2026 (America/Denver).

## Scope and limits

All 236 original directory entries were checked, including write-ins and territories. One entry was a non-person runoff placeholder. The corrected directory contains **239 candidate entries: 153 Senate and 86 Governor**. The table retains the rejected placeholder as a separate audit trail, for 240 rows total. Eighteen photographs were verified and updated to local JPEG assets; **221 current candidates still lack a verified reusable headshot** (219 unavailable, two requiring rights review). No new photo is labeled verified solely because a URL resolves.

Names were looked up individually on their linked 2026 race pages using the web reader. Governor names and parties were also compared with the [NGA 2026 election directory](https://www.nga.org/governors/elections/), including its embedded state records. Ballotpedia raw downloads returned CloudFront 403 pages; web-reader lookups were used instead. General-election sections and November 3 context were then checked separately from primary, withdrawal and historical sections. The election-status column records current race-page listings, write-ins, source-name variants and remaining reconciliation work. These sources do not substitute for official ballot certification. This is a complete inventory and source-check pass, **not a completed official-ballot certification or exhaustive campaign-photo search**. Outstanding cases remain manual work.

The NGA roster contains errors and differs from linked race pages. Oklahoma’s misspelled Cydni Munson and non-person “August 25 Primary Runoff Winner” were corrected to Cyndi Munson and Mike Mazzei; three independent nominees were added from the [current Oklahoma race page](https://ballotpedia.org/Oklahoma_gubernatorial_election,_2026). Virgin Islands scraped heading text and missing independent party labels were corrected using its [current race page](https://ballotpedia.org/U.S._Virgin_Islands_gubernatorial_and_lieutenant_gubernatorial_election,_2026). Other roster discrepancies, including Maine’s Rick Bennett, require further ballot-source review; no identity was inferred from a similar name.

## Photograph method

Existing Commons file-description pages were checked for the named subject, congressional/government origin, and public-domain licensing. Downloaded bytes were decoded and visually inspected in a labeled contact sheet. Some original and Special:FilePath requests returned Wikimedia HTML errors/HTTP 429; documented 250px thumbnails succeeded for Roger Marshall, Mike Rounds, Mark Warner, Doug Jones and Tommy Tuberville. The resulting 18 JPEGs are served from `public/candidates/2026/`, scaled to at most 480px, with source attribution retained. They are archival official portraits, not claimed to be 2026 campaign photographs. Identical CSS controls dimensions, cropping and initials fallbacks in both offices. Local hosting eliminates reliance on expiring URLs and external image loading policies.

Katie Hobbs and Sarah Huckabee Sanders were identified on their NGA profile pages, but those pages did not establish reusable licensing. Their hotlinks were removed pending permission. For candidates without a reliable reusable original, initials remain visible. “Unavailable” means not obtained and verified in this pass, not that no photograph exists anywhere. Reuse permissions were checked as source metadata; no claim is made that federal public-domain status grants endorsement or unrestricted personality rights.

## Governor polling refresh

A direct request to `https://pollingsource.com/api/v1/races` returned HTTP 503 and the JSON error “race list temporarily unavailable; retry shortly.” The response included `Access-Control-Allow-Origin: *`; the observed failure is the upstream race-list service, not a Governor-only office-filter or CORS failure. Both offices use this endpoint. The app retains prior data, displays an accessible concise notice with expandable HTTP details, and offers a Governor polling refresh control. **The upstream outage is unresolved**; no substitute polling figures were created. The regression test verifies 503 rejection, recovery on a later valid payload, null averages, and office separation.

## Validation

- `npm run typecheck`: passed.
- `npm test`: 36 passed, zero failed, including provider outage/recovery and closing-wave checks.
- `npm run build`: passed; existing Vite configuration and bundle-size advisories remain.
- Headless Chrome at 1440px and 390px: both offices render 50 states and the same three tabs; all 12 office/view/viewport combinations keep focus previews inside the map card with no horizontal overflow. Escape dismisses previews; Enter opens candidate details from closing views. Selected portraits loaded at 58 × 74px in both offices. No browser runtime exceptions observed.

Files changed for this work: `src/App.tsx`, `src/GovernorMap.tsx`, `src/ElectionMapUI.tsx`, `src/LiveElectionStatus.tsx`, `src/index.css`, `src/senate.ts`, `src/governors.json`, `src/governor-portraits.ts`, `src/polling.test.mjs`, this report, and the 18 JPEG assets plus attribution README under `public/candidates/2026/`. Existing and concurrent workspace edits were left in place. No commit, push, or deployment was performed by this audit.

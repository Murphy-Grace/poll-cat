# 2026 Senate directory coverage

Checked November 3, 2026. The directory in `src/senate.ts` is independent of polling, forecasts, and live results. It contains 153 general-election entries across all 35 election states, including explicitly listed write-ins. Each state links to the general-election section used to check its field. Primary losers and withdrawn candidates are excluded. This is an editorial snapshot, not a claim of independently certified ballot coverage from every state agency.

The election roster has 33 regular races plus Florida and Ohio special elections. [FEC election schedule](https://www.fec.gov/resources/cms-content/documents/2026pdates.pdf) and [Ballotpedia election directory](https://ballotpedia.org/United_States_Senate_elections,_2026). Oklahoma is a regular election. Existing saved Ohio/Oklahoma associations migrate to the corrected seat IDs.

All 35 states have sourced candidate information; no election state has an empty directory. All states still have at least one portrait needing verification. There are 15 sourced public-domain photographs and 138 neutral placeholders. Missing photos and failed remote images never fall back to a different person. Photo credits and Wikimedia file/license pages appear in the profile cards.

## Data maintenance

Recheck each linked 2026 general-election field against current state election records before updating the dated snapshot. Preserve write-in labels and ballot party labels. Do not promote a primary candidate, hypothetical polling matchup, or forecast participant to general-election status. Verify both identity and reuse permission before adding a portrait. A missing portrait means no verified asset has been stored; it does not mean no photograph exists anywhere.

Vote totals remain in `src/results.ts`. Profiles attach only exact case/spacing-normalized names from the matching state and seat. This intentionally leaves ambiguous/abbreviated feed names unmatched; all provider rows remain available in the results view. Missing totals are shown as unavailable, not fabricated zeroes. Polling values never become election votes. The directory check date and live results source timestamp are displayed separately.

Mouse hover and keyboard focus show the cursor/element-anchored tooltip. Enter, Space, click, and touch select a state and focus its inline profile panel. Escape dismisses the tooltip. Selection remains pinned while other states are hovered. Fifteen states without a race show “No U.S. Senate election in 2026.”
